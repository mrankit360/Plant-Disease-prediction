# 🌿 Plant Disease Prediction using TensorFlow

## Overview

This project is a **Plant Disease Prediction** system built using **TensorFlow** and Deep Learning. The model is trained to identify diseases in plant leaves from images, enabling fast and accurate disease diagnosis for agricultural applications.

The model has been trained on a dataset containing **50,000+ images** across **38 different plant disease classes**, achieving high classification performance through a Convolutional Neural Network (CNN).

---

## Features

* 🌱 Predicts plant diseases from leaf images
* 📊 Trained on **50,000+ labeled images**
* 🏷️ Supports **38 plant disease classes**
* 🤖 Built using **TensorFlow/Keras**
* ⚡ Fast inference for real-time predictions


---

## Dataset

* **Total Images:** 50,000+
* **Number of Classes:** 38
* **Image Type:** Plant leaf images
* **Framework:** TensorFlow / Keras

The dataset contains healthy and diseased plant leaf images from multiple crop species, allowing the model to learn robust visual features for disease classification.

## Model Architecture

The model is implemented using TensorFlow's deep learning APIs and consists of multiple convolutional layers followed by pooling, dropout, and fully connected layers for image classification.

Typical architecture includes:

* Convolution Layers
* Max Pooling Layers
* Dense Layers
* Softmax Output Layer (38 Classes)
